# 🧠 Mindly Backend (Go + PostgreSQL)

This is the backend server for the **Mindly Blogging Platform**, built using **Go** and **PostgreSQL**. It handles user authentication (JWT), image uploads, and post creation.

---

## 🔧 Stack

- **Backend**: Go
- **Database**: PostgreSQL
- **Authentication**: JWT
- **File Storage**: Local (uploads folder)
- **CORS**: Enabled for frontend at `http://localhost:3000`
